📦 حزمة لوحة تحكم mwan3 الجاهزة للراوتر

هذا المجلد يحتوي على ملفات التثبيت السريعة لـ OpenWrt.

🚀 كيفية رفع واجهة React المبنية إلى هنا:

قم بتشغيل أمر البناء المحلي أولاً:

npm run build

ثم انسخ الملفات الناتجة داخل المجلد dist/* إلى هذا المسار /www/mwan3-dashboard/ على الراوتر الخاص بك، أو قم بإنشاء حزمة الـ ipk باستخدام الملفات المضمنة في مجلد /openwrt-ipk.
